# Java OOP Retail System

## Overview

This project is a console-based food ordering and management system developed in Java as part of my Object-Oriented Programming studies.

The application was designed to simulate the day-to-day operations of a small food business. It allows users to manage customers and employees, create and manage orders, schedule activities, and generate invoices.

The project gave me practical experience in developing a structured application from planning and design through to implementation and testing.

## Project Features

The application allows users to:

- Create, view, and manage customer food orders
- Keep customer information organised
- Manage employee and staff information
- Schedule activities and assign them to employees
- Automatically generate invoice summaries
- Calculate order and transaction totals
- Navigate the system through simple menus and prompts
- Prevent incorrect information from being entered
- Handle unexpected errors without crashing the application
- Store and manage information while the application is running
- Test key features to ensure the system works correctly

---

## How It Works

The system provides users with a menu-driven interface where they can select different options depending on what they want to do.

For example, a user can:

1. Add or manage customer information
2. Create a food order
3. Select the required items
4. Calculate the transaction total
5. Generate an invoice summary
6. Schedule activities and assign employees
7. Review or manage existing information

The application is designed to demonstrate how different parts of a business process can work together within one system.
